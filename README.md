## &nbsp;Sobre mí

Soy desarrollador **Full Stack** enfocado en construir aplicaciones completas,
seguras, mantenibles y escalables, desde el diseño de APIs y reglas de negocio
hasta el desarrollo de interfaces web.

En backend trabajo principalmente con **Python y FastAPI**, así como con
**Java y Spring Boot**. Para el desarrollo frontend utilizo **TypeScript**,
**Angular** y **Vue.js**, priorizando interfaces desacopladas, eficientes y
orientadas a una buena experiencia de usuario.

Priorizo el código legible, tipado y testeable, la seguridad, el rendimiento, 
la automatización mediante CI/CD y la construcción de soluciones escalables.
